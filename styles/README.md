# 画風（styles）

同じネーム（OMNY）を、別の画風で刷り直すための画風ファイル集です。**1つの画風＝1つのファイル**で、増やすときはファイルを足すだけです。

```bash
./scripts/styles.sh                       # 一覧
./scripts/styles.sh show crayon           # 中身を見る
./scripts/forge.sh -n my.omny.yaml -s crayon -o out/my_crayon   # クレヨン画で焼く
```

`-s` には、ファイル名（`.yaml` を除く）・`name` に書いた表示名（例 `-s クレヨン`）・表示名の一部（例 `-s セル画`。候補が1つのときだけ）・ファイルのパスのどれを渡してもかまいません。
`-s` を付けないと、OMNY のまま焼きます。OMNY に画風の行がなければ、標準のアニメ塗りのカラー漫画になります。

## しくみ

`forge.sh -s` は、画風ファイルの `line` を OMNY の `meta.style_notes` の**先頭**に入れてから作画AIへ渡します。

```yaml
style_notes:
  - "画風: クレヨン画のカラー漫画（…）。キャラクターデザイン・線のタッチ・デフォルメ度・目や髪の描き方・効果トーンをこの画風に合わせて全編で統一する"
  - （作品の style_notes はそのまま続く）
```

- これは、ネーム生成プロンプト（`prompts/ndm-v10.md` の手順11）が「画風」を指定されたときに出す行と同じ形です。OMAY の優先順位では `meta.style_notes` が `[style]`（標準のカラー漫画）より強いので、画風が確実に上書きされます。
- OMNY にすでに「画風:」で始まる行があれば、その行と差し替えます。だから、同じネームを何度でも別の画風で刷り直せます。
- OMNY のファイル自体は書き換えません。実際に作画AIへ渡したネームは、出力先の `<OMNY名>.used.omny.yaml` に残ります。納品や後工程にはこちらを使います。
- `memo` に書いた念押しは、依頼文の【この作品について】（`-m` と同じ欄）に足されます。

## 画風を足す

1. `_template.yaml` をコピーして、`<英小文字とハイフンの名前>.yaml` で保存する（例 `gouache.yaml`）
2. `name`・`line`（必須）と、`memo`・`tested`・`notes`（任意）を書く
3. `./scripts/styles.sh check` で書き方を確かめる
4. 試し焼きして、結果を `tested` に書く。先頭に効き具合の印を付ける：◎ 顔まで変わる／○ 塗り・線・質感ははっきり変わるが顔はアニメ寄り／△ 少し変わる程度

書き方の決まり：
- 値はすべて1行で、ダブルクォート `"` で囲みます。値の中にダブルクォートは使いません（「」を使う）。
- `line` は「画風: 」で始め、「。キャラクターデザイン・線のタッチ・デフォルメ度・目や髪の描き方・効果トーンをこの画風に合わせて全編で統一する」で締めます。
- `notes` は人間向けのメモです。作画AIには渡しません。

### 自分だけの画風フォルダ

リポジトリに入れたくない画風は、別のフォルダに置いて、環境変数 `MANGA_FORGE_STYLES` にそのフォルダを入れます。

```bash
export MANGA_FORGE_STYLES=~/my-manga-styles
./scripts/styles.sh            # styles/ と自分のフォルダの両方が出る
```

同じファイル名・同じ表示名があれば、自分のフォルダのほうが先に使われます。

## 画風を決めるコツ

- 地続きの画風（水彩絵本など）は、変化が小さめです。**大きく変えたいときは「画材＋支持体（紙など）」を書く**——クレヨン＋画用紙、墨＋和紙、色画用紙を切って貼る、など。
- 「アニメ塗り・デジタルのなめらかな塗りは使わない」「中途半端にきれいにしない」と念押しすると、振り切ってくれます（同梱の画風は `memo` に入れてあります）。
- ピクセルアートのように、質感そのものがキャラの一部になっているキャラは、どの画風でもその質感を保ちます（水墨画では、それが唯一の色になって決まります）。
- 画風を変えても、キャラクターの識別記号（髪・耳・衣装のパーツ・固有色）は省かれません。OMAY の `[const]` で「その画風の描き方に翻訳して残す」と決めてあるからです。
- ⚠️ 同じセッションで続けて別の画風を頼むと、前の画材を引きずります（`docs/pitfalls.md` 罠4）。`forge.sh` は毎回新しいセッションで page1 を始めるので、刷り直しは `forge.sh` をもう一度実行すれば大丈夫です。
